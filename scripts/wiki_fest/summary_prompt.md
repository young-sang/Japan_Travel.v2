# 축제 설명 요약 · 날짜 추출 지시문 (D-092)

`scripts/wiki_festivals.py batches` 가 만든 묶음 파일 하나를 받아 한국어 이름 · 설명 · 개최 시기를 쓴다.
여행지 지시문(`scripts/wiki/summary_prompt.md`)과 같은 규칙에 날짜 추출과 제외 표시가 더해진다.

## 입력

`scripts/wiki_fest/batches/batch_NN.json` — 축제 배열. 각 칸:

- `key` : 출력의 키 (ja 문서 제목)
- `pref` : 도도부현 (한국어)
- `ja` : ja 위키백과 문서 제목
- `kana` : 읽기 (없을 수 있음)
- `name` : 정해진 한국어 이름. `null` 이면 내가 정한다
- `source` : ja 위키백과 원문 (도입부 + 섹션, `【제목】` 으로 구분)

## 출력

`scripts/wiki_fest/summaries/batch_NN.json` — `{ "<key>": { ... }, ... }`. 입력의 모든 축제를 빠짐없이 쓴다. UTF-8, JSON 한 덩어리.

쓸 수 있는 축제:

```json
{ "name": "...", "description": "...", "month": 8, "date_text": "8월 2~7일", "venue": "青森市" }
```

`venue` 는 원문에 적힌 주 개최지 시 · 정 · 촌의 **일본어 표기 그대로**(예: 「青森市」「平泉町」). 지도 좌표를 찾는 데 쓴다. 여러 곳이면 원문이 가장 먼저 드는 곳 하나. 원문에 없으면 `null`.

뺄 축제 (아래 "제외" 에 해당):

```json
{ "skip": "이유 한 줄" }
```

## 제외 — 다음이면 `skip` 으로 쓴다

1. **개최 시기를 원문에서 찾을 수 없다.** 월을 짐작하지 않는다 (D-092).
2. **지금 열리지 않는다.** 원문에 폐지 · 중단 · 종료가 적혀 있고 다시 열린다는 내용이 없다.
3. **관광객이 보러 갈 축제가 아니다.** 방송국 · 기업 행사, 영화제 · 음악 공연 · 경연, 집안 · 개인 풍습, 축제 묶음이나 목록 문서, 특정 장소 없이 전국에서 하는 풍습.

## 이름 규칙 (`name` 이 `null` 일 때만)

- 국립국어원 일본어 표기법으로 음역한다. 祭り · 祭 → "마쓰리", 花火大会 → "불꽃 대회", 踊り → "오도리" 처럼 한국에서 흔히 쓰는 표기를 따른다 (예: 祇園祭 → 기온 마쓰리, 長岡まつり大花火大会 → 나가오카 마쓰리 대불꽃 대회).
- 읽기는 `kana` 를 따르고, 없으면 원문 첫 문장의 괄호 속 읽기를 따른다. 괄호 구분어는 넣지 않는다.

## 날짜 규칙

- `month` : 1~12 정수. 주로 열리는 달 하나. 여러 달에 걸치면 **시작 달**.
- `date_text` : 원문에 있는 개최 시기를 한국어로 짧게. 예: "8월 2~7일", "7월 셋째 일요일", "2월 상순 약 1주일", "매년 10월 22일". 해마다 바뀌는 경우 원문의 규칙을 쓴다. 연도는 넣지 않는다.
- 옛 음력 날짜만 있고 지금의 양력 시기가 없으면 제외 1에 해당한다.

## 설명 규칙 (여행지와 같다)

1. 원문 안의 내용만 쓴다. 원문에 없는 사실 · 평가 · 여행 팁을 더하지 않는다.
2. 길이 500~1,000자(공백 포함). 원문이 짧으면 짧아도 된다. 늘리려고 되풀이하지 않는다.
3. 숫자 · 연도는 원문 그대로. 원문이 연호로만 적었으면 정확히 환산한 서기는 써도 된다.
4. 2~4 문단, 문단 사이는 빈 줄(`\n\n`). 첫 문단은 무엇이고 어디서(시 · 정 단위) 언제 열리는지, 다음 문단부터 유래 · 행사 내용 · 볼거리 중 원문에 많은 것. 소제목 · 목록 · 마크다운은 쓰지 않는다.
5. 빼는 것: 교통 · 주차 · 요금 · 전화번호, 각주 표시, 「후술」 같은 원문 내부 참조, 해마다 바뀌는 관객 수 나열(대표 수치 하나는 괜찮다).
6. 평서문 "~다" 체. 신앙 · 전설은 "~라고 전한다" 처럼 원문의 단정 수준을 지킨다.

## 끝나면

출력 파일을 쓰고, 축제 수 · `skip` 한 축제와 이유 · 500자 미만으로 쓴 축제만 짧게 보고한다.
